# 复盘

核心难点是区分“引用存在”与“原文支持回答”，以及区分真实模型决策和固定流程测试。当前采用读取原文后引用校验，并将离线与真实模式明确分开。

已知限制：中文关键词召回弱；引用只做精确片段匹配，未验证全部事实的语义支持；未实现制度适用范围推理、访问控制、持久会话及跨请求预算；真实模型尚未实测。

下一步优先进行真实模型验收，记录失败案例；增加改写检索与排序、语义支持检查及文档权限。版本日期不直接代表制度优先级。

实际用时与个人学习收获由候选人补充。当前尚未完成远端仓库提交和真实模型验证。

## 当前进展

真实模型已完成小样本验收，新增原文片段定位、冲突追加查证和替换文档验证。旧文中“尚未实测”是历史状态，以最新评估记录为准。当前重点限制仍是语义支持未自动严格证明、小语料检索无法代表企业规模表现、未测多轮稳定通过率；未宣称生产级可靠性。
