# AI使用记录

本初始实现由Codex辅助生成：需求整理、LangGraph编排、模型接入、合成资料、测试和交付文档。参考仓库仅用于交付目录规范，未作为真实Agent答案。

验证范围为本地离线测试和CLI运行；没有配置真实模型凭据，未获得真实模型质量证据。

候选人的个人设计取舍、修改、独立验证、实际投入时间尚待本人如实补充，不能将自动生成内容描述为个人独立完成。最终提交前应检查全部代码并能解释模型动作、引用校验及边界。

后续按用户授权配置本地.env，接入DeepSeek，实际运行六类问题并根据协议失败增加有限格式修复。真实输出见examples/live/。

本轮由Codex根据题目验收点完善片段读取、词法检索、模型查证提示和评估工具，使用已授权DeepSeek配置进行真实对照测试，未增加Embedding、Milvus或Elasticsearch。个人贡献和实际投入仍由候选人如实填写。
